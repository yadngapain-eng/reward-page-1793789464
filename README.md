## Deploy Cloudflare Pages
1. Push repo ke GitHub
2. Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git
3. Pilih repo ini
4. Framework preset: None
5. Build command: (kosongkan)
6. Build output directory: / (root)
7. Deploy
