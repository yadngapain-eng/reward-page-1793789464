# Duniamu — Baca Novel, Raih Reward

Website statis bergaya platform novel, terinspirasi konsep NovelToon.
Dibuat orisinil tanpa menyalin aset atau kode pihak ketiga.

## Fitur

- Beranda: hero, katalog novel, filter genre
- Reader: baca per bab, reward +20 koin per bab
- Library: daftar novel tersimpan
- Reward: check-in harian (+50), misi, tukar koin
- Profil: statistik & riwayat, reset progres

## Deploy

- GitHub Pages: Settings > Pages > Branch main / root
- Cloudflare Pages: Framework None, output /

## Catatan

- State disimpan di localStorage (tanpa backend)
- Ganti data novel di data/novels.json
